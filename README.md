## 📊 V3.1 / V3.2 双轨制量化策略架构与 5 年回测表现矩阵

针对美股高波动科技股与大盘宽基指数特征，本系统在 V3.1 版本确立了双轨制量化运行框架，并在 V3.2 中引入严格的暴跌熔断与防接飞刀军规：

### 1. 双轨制策略定义

#### 轨道一：Track 1 (Pure Stock Dynamic Risk-Managed / 纯个股动态风控轨)
- **核心逻辑**: 精选 54 只高 Alpha 科技个股与赛道龙头，采用 1.5% 账户风险平价动态头寸计算，最多同时持仓 4 只个股（单股上限 25%）。
- **利润奔跑与风控保护**: 保全 EMA10/EMA20 移动止盈机制与大牛股暴利波段（历史捕获 ASML +30%、AMD +37%、AVGO +22%），同时设置 -6.8% 结构性硬止损，彻底化解频繁 2.0% 窄幅止损带来的磨损。
- **回测特征**: 5 年最大回撤仅 **-11.31%**（较 V3.0-A 的 -24.98% 压缩 54.7%），Calmar 比率提升至 **0.51**。

#### 轨道二：Track 2 (Flagship QQQ Base Enhancement / QQQ 核心底仓增强旗舰轨)
- **核心逻辑**: 以科技大盘基准 QQQ 作为流动性停泊底座。当 QQQ > SMA200 时，所有闲置现金（保留 $500 缓冲）全额停泊 QQQ 捕捉大盘 Beta；当 QQQ 破位 SMA200 时，坚决清仓避险防守。
- **动态扫单解锁 (Dynamic Sweep)**: 当卫星个股出现确定性黄金坑买点时，系统自动精准计算所需资金并卖出等额 QQQ 释放流动性买入个股（最多 3 只卫星个股）。个股获利了结后资金立即回流 QQQ 底仓。
- **回测特征**: 5 年期末总资产 **$187,910.80**（净收益 **+87.91%**），CAGR **+14.24%**，最大回撤 **-19.03%**，Calmar 比率 **0.75**，相较频繁调仓策略交易摩擦滑点大幅减少 **88.4%**。

## 💵 Firstrade 实盘交易摩擦与滑点精准校准

系统全面根据 Firstrade 美股券商实盘交易特性完成参数校准：
1. **$0.00 零佣金**: 美股正股与 ETF 买卖交易全免手续费。
2. **超大市值与流动性标的 1~2 bps 滑点模型**:
   - 监控池内均为高流动性标的（平均买卖价差 1~2 美分）。
   - 买入撮合成交价 = $P_{quote} \times (1 + \text{Slippage})$（默认 1.5 bps = +0.015%）。
   - 卖出撮合成交价 = $P_{quote} \times (1 - \text{Slippage})$（默认 1.5 bps = -0.015%）。
   - 复利级穿透计入每笔挂单与成交的损耗，回测收益不掺水。

## 🚨 V3.2 暴跌熔断与防接飞刀军规体系

针对极端行情的“黑天鹅断头铡刀”与“阴跌飞刀”，系统搭载了 V3.2 动态风控熔断引擎：

1. **动态 ATR 暴跌熔断闸 (`eff_atr`)**:
   - 依据个股真实波动率计算动态回撤阈值，winsorize 截断至 $[1.2\%, 5.0\%]$。
   - 严禁低波动股票与高杠杆品种共用同套固定止损线。
2. **断头铡刀日内大跳水保护**:
   - 标的若出现日内高开低走急速跳水或盘后跳空大跌，日内买点自动熔断（`is_crash_halt = True`）。
   - 终端与 AI 看板即时高亮展示：`🚨 暴跌熔断·严禁左侧接刀`，强制冻结首笔买单。
3. **3 日暴跌宣泄期冷却锁 (`prev_crash_3d`)**:
   - 标的在过去 3 个交易日内曾发生单日暴跌时，自动锁定 3 日冷静观察期（`is_cooling_halt = True`）。
   - 杜绝反弹一日游诱多死猫跳。
4. **解锁条件与跳空漏检防范 (`unlock_a`)**:
   - 严格要求昨日必须收出右侧确认阳线，**且今日必须未出现新跳空暴跌**（`pct_change > -3.8%` 且 `ext_pct > -4.5%`）。
   - 若今日再度低开低走，强制进入持续熔断，绝不逆势做多。
5. **反向损耗对冲 ETF 物理隔离铁律**:
   - `SQQQ`、`SOXS`、`VIXY` 等反向杠杆与波动率对冲衍生品自带时间损耗，系统物理隔离其信号，**严禁将其计入黄金坑多头进攻标的**。
